# 🤖 Tukkata Lom Luk | AI LINE Chatbot

เทคโนโลยีเพื่อส่งต่อกำลังใจให้ผู้คน

สถานะโครงงาน: Deployed — ทดลองใช้งานผ่าน LINE ได้แล้ว

## 📖 เกี่ยวกับโครงงาน

ตุ๊กตาล้มลุกเป็นโครงงาน LINE Chatbot ที่เกิดจากความตั้งใจในการนำเทคโนโลยีมาช่วยรับฟังและส่งต่อกำลังใจให้ผู้คน

ระบบเชื่อมต่อกับ Gemini AI ผ่าน API เพื่อประมวลผลข้อความของผู้ใช้และสร้างคำตอบตามบริบท แทนการตอบด้วยข้อความที่กำหนดไว้ล่วงหน้าเพียงอย่างเดียว

## 💻 เทคโนโลยีที่ใช้

- Python — ภาษาหลักในการพัฒนา
- Flask — ระบบ Web Server และ Webhook
- LINE Messaging API — รับและส่งข้อความผ่าน LINE
- Gemini API — ประมวลผลและสร้างข้อความตอบกลับด้วย AI
- Render — ให้บริการเซิร์ฟเวอร์ออนไลน์
- GitHub — จัดเก็บโค้ดและบันทึกการพัฒนา

## ⚙️ หลักการทำงาน

1. ผู้ใช้ส่งข้อความผ่าน LINE
2. LINE ส่งข้อมูลมายัง Webhook บน Render
3. โปรแกรม Python รับและประมวลผลข้อความ
4. ระบบเรียก Gemini API เพื่อสร้างคำตอบ
5. บอทส่งข้อความกลับไปหาผู้ใช้ผ่าน LINE

## 🧪 การทดสอบและพัฒนา

โครงงานผ่านการทดสอบรับและตอบกลับข้อความผ่าน LINE จริง รวมถึงแก้ปัญหาที่พบระหว่างการพัฒนา เช่น การตั้งค่า Webhook, Environment Variables และการเชื่อมต่อ API

## 👩‍💻 บทบาทในการพัฒนา

ผู้จัดทำเป็นผู้กำหนดแนวคิด วัตถุประสงค์ รูปแบบการทำงานของบอท และดำเนินการตั้งค่า ทดสอบ และปรับปรุงระบบ โดยใช้เครื่องมือ AI ช่วยในการเขียนโค้ดและแก้ไขข้อผิดพลาด พร้อมเรียนรู้กระบวนการทำงานของระบบ

## 🌱 สิ่งที่ได้รับจากโครงงาน

โครงงานนี้ช่วยให้ได้เรียนรู้การเชื่อมต่อ API การทำงานของเซิร์ฟเวอร์ การ Deploy ระบบบน Cloud และการแก้ไขปัญหาจาก Logs

เป้าหมายของผู้พัฒนา: ต้องการใช้ความรู้ด้านวิศวกรรมคอมพิวเตอร์สร้างเทคโนโลยีที่เข้าถึงผู้คนและสร้างประโยชน์ต่อสังคม
